Sentiment Analysis on IMDB Movie Reviews using NLP, TF-IDF, Naive Bayes, and Logistic Regression.
**Dataset:** The dataset used for this project is the IMDB Dataset of 50K Movie Reviews. Due to GitHub's 25MB web upload limit, the raw CSV is not hosted here. You can download it directly from [Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews).
